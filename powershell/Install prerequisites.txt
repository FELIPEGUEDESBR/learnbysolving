Install prerequisites
Download the latest visual C redistributable
Install Python 3.10 (Be sure to select add to path checkbox)
Install GIT using the defaults

Reboot

Create the Folder
CD

MD SD
CD SD

Create a virtual environment
Python -m venv venv
Cd venv
Cd scripts
./activate
Python.exe -m pip install --upgrade pip

Verify GPU support
Nvidia-smi
Note the CUDA version (13.1)

Install Pytorch
Uninstall the CPU only version
Pip uninstall torch torchvision torchaudio -y
Go to Pytorch.org (go to Projects and Get Started Locally)
Choose a version of Pytorch that is equal to or lower than the CUDA version that you documented
Copy the command that is generated
Pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu126

Install Core SD packages
pip install diffusers==0.19.1 transformers==4.31.0 accelerate==0.20.3 safetensors==0.3.1 pillow --upgrade

API server
pip install fastapi uvicorn

Hugging Face Token
setx HF_TOKEN ""

Close and restart PowerShell

CD SD
Cd venv
Cd scripts
./activate.ps1

Place Server.PY (which I have already created) into the C:\SD folder

Update Hugging Face
pip uninstall huggingface_hub -y
pip install huggingface_hub==0.16.4

Start the server
CD..
CD..
uvicorn server:app --host 0.0.0.0 --port 7860

The first time you run this it will need to download several files.
